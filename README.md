# AXEL EVOLVE

> A self-evolving AI agent system with dynamic skill acquisition, multi-agent orchestration, evaluation, and continuous improvement.

## Overview

**AXEL EVOLVE** is an AI agent system designed to evolve its capabilities over time.

The project explores how AI agents can:

- Acquire and develop new skills dynamically
- Orchestrate multiple agents to solve complex tasks
- Evaluate their own outputs and behavior
- Learn from evaluation results
- Continuously improve their capabilities

## Core Idea

Traditional AI agents generally operate with a fixed set of capabilities.
